## Publication review

- [ ] Actual source SHAs match the review record.
- [ ] Planned differentiated value appears in the finished book.
- [ ] Adaptation records identify creator, source path, commit, license, changes, translation, destination, and notices.
- [ ] Third-party assets/data/standards have separate records and notices.
- [ ] License and attribution pages ship with the deployed site.
- [ ] No P0/P1 provenance issue remains; P2 work has an owner/action and is disclosed.
- [ ] Human/editorial review is distinguished from automated validation.
