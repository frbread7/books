Reproduction and verification

Capture the final candidate

The comparison above shows the baseline and candidate at 390 px and 1440 px in English light mode. To reproduce the after views, use the exact candidate commit in a clean checkout with dependencies and the cached Playwright Chromium installed. In the first terminal, start the repository's local Pages server:

python3 tests/serve.py

In a second terminal at the repository root, run:

node design/capture-physical-shelf.cjs

The helper verifies that served JavaScript, CSS, and catalog bytes match the checkout, then records a manifest and 52 PNGs under /tmp/books-renaissance-shelf-final/<commit-sha>/. It captures Home and Library at 390 px and 1440 px for English/Korean and light/dark (16 states), plus both routes at 320, 360, 768, 1024, and 1920 px in English light mode (10 responsive states). Each state checks the five rendered books, loaded images, page errors, HTTP/request failures, language/theme, and horizontal overflow; any mismatch makes the command exit nonzero. The HTML comparison itself and its bundled images can be opened offline.
